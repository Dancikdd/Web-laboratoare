1. Care este rolul folderului src?
Folderul src conține codul sursă al aplicației, cum ar fi componentele React, fișierele JavaScript și stilurile CSS.

2. Ce reprezintă fișierul App.jsx?
App.jsx este componenta principală a aplicației React. În acest fișier este definită interfața principală care va fi afișată în aplicație.

3. Ce informații sunt păstrate în package.json?
Fișierul package.json conține informații despre proiect, scripturile disponibile, versiunea proiectului și dependențele necesare pentru funcționarea aplicației.

4. Ce reprezintă folderul node_modules?
node_modules conține pachetele și bibliotecile instalate cu npm de care are nevoie proiectul pentru a funcționa.
